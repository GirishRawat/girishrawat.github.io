## 🧪 Prototypes

### 🏛️ State.com Prototype (Civic Intelligence System)
Located at [`/prototypes/state`](./prototypes/state), this prototype is a design exploration for the **State Product Challenge**. It envisions a "Civic Intelligence System" that acts as an authoritative yet accessible bridge between complex civic data and actionable public discourse.

* **Core Concept:** Evolving a social-first aesthetic into a "Corporate Modern" data dashboard framework that displays high-density civic visualizations.
* **Design System Highlights:**
  - **Color Palette:** Anchored by a vibrant brand pink (`#FF4B91`) with clean, soft neutrals. Uses a dedicated semantic status set (Escalated, Reviewing, Action Taken) to humanize quantitative data.
  - **Three-Font Strategy:** Employs *Hanken Grotesk* for bold headlines and numerals, *Inter* for legible body copy, and *Manrope* for technical labels and metadata.
  - **Conversational UI:** Features a mock AI chat interface (`chat.html`) that simulates querying local constituency issues and public motions across the UK.
  - **Responsive Layout:** Built on a responsive grid that reflows seamlessly from a 4-column dashboard layout on desktop to tablet and single-column mobile views.
